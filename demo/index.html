A quantity stepper that owns the clamping, the bounds and the disabled states — and nothing else. You bring the markup.

Bounds it can't leave.

min defaults to 1, max is open-ended, and value starts at the minimum. Each button disables itself at its own bound — typing out of range snaps back on commit.

defaults
min 5 · max 15 · value 10
min 0 · value 0
<quantity-input min="5" max="15" value="10">…</quantity-input>

Count by sixes.

step sets how much each press moves. Clamping still wins at the edges, so a step that would overshoot lands on max instead.

step 6 · case of six
step 5 · max 22 (clamps short)
<quantity-input min="0" max="24" value="0" step="6">…</quantity-input>

Out of stock.

disabled on the host disables both buttons and the input, and every handler no-ops. Toggle it as a property from JavaScript.

disabled
el.disabled = !el.disabled // or the `disabled` attribute

Enter commits. Nothing submits.

This is a real <form>. Type a quantity and press Enter — the value is committed and the keypress is swallowed, so the form never implicitly submits. The button still does.

Listen in.

Every committed change fires a bubbling quantity-input:change with { value }. Clamped input and no-op presses stay quiet.

min 1 · max 10 · value 5
el.addEventListener('quantity-input:change', (e) => { console.log(e.detail) // { value: 6 } })
